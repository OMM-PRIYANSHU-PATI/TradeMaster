# TRADEMASTER — PHASE 21: GEMINI STRATEGY INTELLIGENCE

## Overview
Phase 21 introduces Gemini-assisted strategy generation and intelligence to TradeMaster. This phase builds on top of the canonical StrategyExecutionEngine (Phase 16) and Backtest Studio (Phase 20) to enable AI as an assistive capability for creating, reviewing, and comparing quantitative strategies.

## AI Boundaries & Safety
- **No Direct Execution**: The AI cannot place orders, modify portfolios, or bypass the RiskEngine.
- **Strict Validation**: All Gemini output is constrained to a strictly defined JSON Schema that matches the canonical `StrategyConfiguration` DSL. Zod schemas validate the output at the boundary.
- **No Code Generation**: Gemini strictly outputs structured data. There is zero reliance on `eval()`, `new Function()`, or dynamic code execution.
- **Human-in-the-Loop**: Strategies generated by Gemini must be reviewed, edited (optional), and backtested by a human before execution.

## Features
### 1. Unified Strategy Creation
Located at `/strategies/create`, the UI provides two paths:
- **Manual Builder**: Directly construct the strategy condition trees.
- **Describe Strategy (AI)**: Translates natural language into a canonical Strategy JSON.

### 2. Strategy Intelligence APIs
- `POST /api/v1/ai/strategies/generate`: Generates the DSL.
- `POST /api/v1/ai/strategies/:id/explain`: Explains the strategy configuration.
- `POST /api/v1/ai/backtests/:id/explain`: Explains a deterministic backtest result using only actual data.
- `POST /api/v1/ai/trades/:id/review`: Reviews an individual trade.

### 3. Unified Strategy Comparison
Located at `/strategies/compare`, this provides a deterministic side-by-side view of multiple strategies' performance metrics (Return, CAGR, Sharpe, Drawdown, Profit Factor). The comparison strictly relies on numerical outputs from the analytics engine (Phase 19).

## Architecture Details
- Reused existing Gemini services from Phase 8-10.
- Enhanced Strategy schema to support tracking of modified strategies with `version` and `parentId` links.
- Augmented Backtest DTOs to return `totalCosts` and `totalSlippage`.
- Extended `StrategyController` with a `/compare` endpoint for loading the latest backtest metrics across multiple strategies.

## Known Limitations
- Gemini output occasionally hallucinate indicators not in the explicitly supported list, though prompt constraints mitigate this heavily. Validation catches failures.
- Time-series synchronization of equity curves in the comparison tool uses placeholder bounds.
